# Design: ติ๊กกรอง phase บนหน้า "งานทั้งหมด" (/portal/jobs)

วันที่: 2026-07-08 · สถานะ: **APPROVED** (กัญจน์ "โอเค ทำเลย ทำให้หมดเลยนะ")
ที่มา: กัญจน์อยากติ๊กดูว่างานอยู่ phase ไหน เช่น รับฟังคำวิจารณ์ — เคาะจาก brainstorm ว่า
"ติ๊ก" = **ติ๊กเพื่อกรอง** บนหน้า `/portal/jobs` อย่างเดียว (ไม่แตะบอร์ด world)

## Decisions (จาก brainstorm 2026-07-08)

1. **ความหมาย**: chip ติ๊กเปิด/ปิดเพื่อกรองรายการงานตาม stage — ไม่ใช่ mark ความคืบหน้าเอง
2. **ขอบเขต**: หน้า `/portal/jobs` หน้าเดียว (world มี ★ filter อยู่แล้ว ไม่เพิ่ม)
3. **เปลี่ยนป้าย** ⚪ `pre` "ระยะวางแผน" → **"รับฟังคำวิจารณ์"** ทั้ง 2 จุด
   (`jobs/_client.tsx` STAGE_LABEL + `world/_client.tsx` STAGE_META) — ในทางปฏิบัติป้ายนี้
   มาจาก `province_tor_review*` ล้วน (ตรวจ prod DB 2026-07-08: 56/253 แถว) ป้ายเดิมกำกวม
4. **กติกา default เดียวกับหมวดงาน**: ไม่ติ๊กเลย = เห็นทั้งหมด; ติ๊ก ≥1 = เฉพาะ stage ที่ติ๊ก (OR)
5. ใช้ร่วมกับช่องค้นหาเดิมแบบ AND (ติ๊ก stage แล้วพิมพ์ค้น = กรองทั้งคู่)

## สถาปัตยกรรม

**Client-side ล้วน — ไม่แตะ engine API / DB / ระบบส่ง LINE** (payload all-jobs มี `stage`
ต่องานอยู่แล้ว, งาน ≤500 กรองบนเบราว์เซอร์สบาย, pattern เดียวกับช่องค้นหาเดิม)

### UI (jobs/_client.tsx)

แถว chip ใต้ช่องค้นหา เรียงตามลำดับ lifecycle เดิมของ STAGE_META:

```
[🔵 ยื่นซองได้ n] [🟡 รอผล n] [🏆 รู้ผลแล้ว n] [⚪ รับฟังคำวิจารณ์ n] [❌ ยกเลิก n]
```

- แต่ละ chip มีจำนวนงานของ stage นั้น (นับจากงานทั้งหมด ไม่ใช่หลังกรองค้นหา — เลขนิ่ง ไม่เด้ง)
- stage ที่มี 0 งาน → ไม่แสดง chip (ไม่มีอะไรให้กรอง)
- state: `Set<SentJobStage>` ใน useState; แตะ chip = toggle; ติ๊กอยู่ = tone เด่น + ✓
- ข้อความ "พบ X จาก Y งาน" แสดงเมื่อมีการกรองใดๆ (ค้นหา หรือ ติ๊ก stage)
- empty state เมื่อกรองแล้วว่าง: ใช้ก้อน "ไม่พบงานที่ตรงกับเงื่อนไข" เดิม

### ป้าย (world/_client.tsx)

แก้ label ตัวเดียว: `{ key: 'pre', label: 'รับฟังคำวิจารณ์', icon: '⚪' }`

## Testing / Verify

1. `npm run build` ผ่าน
2. เปิดหน้าจริง (dev server + seed): ติ๊ก chip แล้วรายการเปลี่ยนถูก, เลขบน chip ตรงกับรายการ,
   ติ๊กหลายอันเห็นรวมกัน, ติ๊ก+ค้นหาทำงานร่วม, เอาติ๊กออกหมดกลับมาเห็นทั้งหมด
3. regression: หน้า world ป้าย ⚪ เปลี่ยนชื่อแล้วเรนเดอร์ปกติ
